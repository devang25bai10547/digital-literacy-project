## 📌 Project Overview
This project was completed as part of the Digital Literacy course. The aim of this project is to develop essential digital skills such as creating a professional online presence, communicating effectively, and staying safe online. The project also focuses on spreading awareness about digital literacy among students.

---

## 📂 Repository Structure

- report/ → Contains the final project report (PDF)
- task-1-presentation/ → Digital Literacy infographic created using Canva
- task-2-portfolio/ → Screenshots of GitHub, LinkedIn, and Kaggle profiles
- task-3-platforms/ → HackerRank coding challenge and Google Form screenshots
- task-4-email-etiquette/ → Professional emails and social media checklist
- task-5-cybercrime/ → Cybercrime case study and prevention checklist

---

## 🧠 Task Summary

### Task 1: Infographic
Created a one-page infographic on digital literacy using Canva, covering topics such as online safety, useful tools, and email etiquette.

### Task 2: Digital Portfolio
Built a professional digital presence by creating profiles on GitHub, LinkedIn, and Kaggle.

### Task 3: Platforms
Solved a beginner-level coding problem on HackerRank and created a Google Form quiz to spread awareness about digital literacy.

### Task 4: Email Etiquette
Drafted professional emails and prepared a checklist for responsible social media usage.

### Task 5: Cybercrime Awareness
Prepared a case study on UPI fraud and created a prevention checklist for staying safe online.
