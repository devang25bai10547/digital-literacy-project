## 📌 Project Overview
This project was completed as part of the Digital Literacy course. The aim is to develop essential digital skills such as creating a professional online presence, communicating effectively, and staying safe online.

---

## 📂 Project Structure

- task-1-presentation → Digital Literacy Infographic  
- task-2-portfolio → Screenshots of GitHub, LinkedIn, and Kaggle profiles  
- task-3-platforms → HackerRank coding challenge and Google Form screenshots  
- task-4-email-etiquette → Professional email drafts and social media checklist  
- task-5-cybercrime → Cybercrime case study and prevention checklist  
- report → Final project report  

---

## 🧠 Task Summary

### Task 1
Created an infographic on digital literacy using Canva, covering key topics like online safety, tools, and email etiquette.

### Task 2
Built a digital portfolio using GitHub, LinkedIn, and Kaggle platforms.

### Task 3
Solved a beginner coding problem on HackerRank and created a Google Form quiz on digital literacy.

### Task 4
Drafted professional emails and created a social media do’s and don’ts checklist.

### Task 5
Prepared a case study on UPI fraud and created a prevention checklist for online safety.
